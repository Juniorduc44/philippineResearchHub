# Session close

1. Read `memory/CONTEXT.md` and current `memory/PICKUP.md`.
2. Replace `memory/PICKUP.md` with: last workspace, files touched, next action (one bullet), blockers.
3. If this turn created or changed an idea or library card, write `memory/sessions/<yyyy-mm-dd>-<topic>.md` with five lines or fewer: goal, wrote, leftover.
4. If a binding choice was made, append a row to `memory/decisions.md`.
5. Confirm the pickup path in the reply. Do not dump the full files.
