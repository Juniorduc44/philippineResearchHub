AI workflow integrator

Most companies here do not need an AI engineer. They need Gmail + sheets + tickets + a simple assistant to stop living in separate tabs. Setup, train, then charge monthly to keep the glue working. Photos are generated portfolio stills, not a paying Cebu site. No PHP quote on disk. Ladder: Phase 1 — cash.

Why it may be a quality opportunity

Zero inventory. The same field visits that sell managed IT surface workflow pain. Restaurant, hotel, cleaning, and property-manager examples are already in the operator brief.

For

  • Laptop business
  • Feeds the MSP retainer
  • Training is already an operator skill
  • Repeat change-requests

Against

  • Vendor UI churn
  • Customers want magic, not SOPs
  • No Cebu reference yet
  • DPA path unknown if data leaves the tenant

How practical

Start as a line item on the Checkup, not a separate company. One paid restaurant or hotel workflow before a brand name.

To take it up

  1. Pick one vertical (hotel or restaurant).
  2. Build one demo tenant with fake data.
  3. Sell setup + 90-day care.
  4. Write the SOP so a second person can run it.
