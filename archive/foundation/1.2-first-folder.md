# 1.2 Your First Folder (extract)

A working folder that changes how the model responds. Three files. The folder carries context so you do not re-explain every chat.

## Three files
- `CLAUDE.md` — who it is working for and how to behave. Keep short.
- `CONTEXT.md` — what we are building, what good looks like, what to avoid.
- `REFERENCES.md` — background, not acting instructions.

Claude Code reads the folder automatically. Browser users paste or upload the files.

This is the starting point. Full architecture (three layers, routing tables, naming conventions) is Section 3.
