# 3.2 Customizing for Your Use Case (extract)

Layers do not change. Labels do.

1. Top-level identity file (`CLAUDE.md`) routes everything.
2. Each workspace has a `CONTEXT.md`.
3. Skills/tools plug in only where needed.

Build yours: list 2–4 workspaces (mode shifts), write one `CONTEXT.md` each (under a page), write `CLAUDE.md` with a routing table and naming conventions, then start working. Context files are living notes.

This hub's three workspaces: `/directory`, `/research`, `/memory`.
