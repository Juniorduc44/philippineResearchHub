# 3.3 Common Mistakes (extract)

1. `CLAUDE.md` too long. It is a routing file. One screen. Identity, folders, routing table, naming. Everything else goes in a workspace CONTEXT.md.
2. Skipping the routing table. Task / Go to / Read. Optional Skills column.
3. Too many workspaces. Start with two or three. Split only on mental-mode shifts.
4. Context files that describe AI personality instead of the work. 80% work, 20% behavior.
5. Never updating context files. Add a last-updated line.
6. One flat folder. More than 8–10 files at one level needs subfolders.
7. Building the whole system before using it. Minimum first; grow from real work.

Pattern: keep it small, focused on the work, updated as you go. Map, rooms, tools.
