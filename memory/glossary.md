# Glossary

| Term | Meaning here |
|------|----------------|
| Hub | This repository. Not a website. |
| Directory | `/directory` — business ideas on disk. |
| Idea | One folder under `directory/ideas/<slug>/`. |
| Library card | A markdown file in `research/library/` that cites a downloaded source. |
| Inbox | Raw download bytes. Not for citing. |
| Pickup | `memory/PICKUP.md` — current next action. |
| Routing | The table in `CLAUDE.md`. |
| Local-first | Search inbox/library/index before any browser or web_search call. |
| Example entry | Format specimen. Not evidence. |
| Project | `/projects/<slug>/` — expanded build of a catalog idea. |
| Operator-brief | Hub-authored note. Not proof. |
| CAP / TAP | Profit First current vs target allocation percentages. |
| MVP | One-site test, not a mini-brand. |
| LGU | Local government unit (city/municipality + barangay permits). |
| DTI / SEC / CDA | Business name, corporation, cooperative registration paths. |
| BIR | National tax registration. |
| PSA / BSP / NEDA | Statistics, monetary, planning sources. |
| God's Eye View / `godseye` | Local 3D globe (`tools/gods-eye-view`). Live public layers. Not a citeable primary source until snapshotted. |
