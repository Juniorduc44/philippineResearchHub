# Memory workspace

Last updated: 2026-09-20

## What happens here
Durable notes for this hub. New sessions start here after `CLAUDE.md`.

## What the work is
Keep a short, current picture of where work stopped, which decisions are binding, and which words this repo uses in a special way. This is working notes, not a diary.

## Process
- On session start: read `PICKUP.md`. Then only the workspace the routing table names.
- During work: if a decision is made, append `decisions.md` the same turn.
- On session close: rewrite `PICKUP.md` (replace, do not append forever). Write a short file in `sessions/` only when the turn produced durable work.

## What good looks like
- `PICKUP.md` fits on one screen. Next action is a single bullet.
- Decisions have a date, a choice, and a reason.
- Glossary terms are PH-specific or hub-specific, not a general dictionary.

## What to avoid
- Pasting chat transcripts.
- Duplicating idea dossiers or source cards.
- Stale pickup. If it is older than the latest idea or source, rewrite it.

## Files
- `PICKUP.md` — where we left off
- `decisions.md` — binding choices
- `glossary.md` — hub terms
- `sessions/` — optional dated notes
