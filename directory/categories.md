# Categories

Use one primary key per idea. Add a key here before using it.

| Key | Means |
|-----|--------|
| agri | Farming, fisheries, post-harvest, inputs |
| food | Food service, processing, packaged food |
| retail | Sari-sari, specialty retail, distribution |
| services | Local trades, personal, professional services |
| tourism | Travel, hospitality, experience |
| logistics | Transport, warehousing, last mile |
| digital | Software, content, online services targeting PH users |
| education | Training, review, TESDA-adjacent |
| health | Clinics, wellness, elder care (permits are strict) |
| energy | Solar, fuels, efficiency |
| manufacturing | Make-and-sell, crafts at scale |
| green | Waste, water, circular |
| housing | Construction, rental, facilities |
| finance | Payments, lending, cooperatives (heavy regulation) |

Do not invent overlapping keys (`agri-food`). Pick one primary. Secondary tags go in the idea body as a line `Tags: a, b`.
