# Franchise prototype (one unit)

Gerber (p.81): pretend this kiosk is the model for 5,000 just like it. We are not franchising. We are refusing a one-off hobby.

| Rule | Applied here |
|------|----------------|
| 1. Consistent value beyond expectation | Helmet back dry, not dripping; receipt or SMS if QR; machine looks clean even if the parking lot does not |
| 2. Lowest skill that still works | Refill, collect, wipe, reboot. No “helmet sommelier.” Systems, not a star technician (p.82) |
| 3. Impeccable order | Cover, level, no tangled wires, no handwritten price on masking tape that peels in rain (p.84) |
| 4. Operations manuals | `emyth/systems/` — purpose, steps, standard (p.85) |
| 5. Uniformly predictable service | Same cycle time band, same posted price, same “lid closed / pay / wait / take” |
| 6. Uniform look | Same wrap, same instruction sticker, same price card — cloneable to unit 2 |

Technician trap (p.29): default owner mix is 70% Technician. If the founder is the only person who can refill, the prototype has already failed the clone test.
