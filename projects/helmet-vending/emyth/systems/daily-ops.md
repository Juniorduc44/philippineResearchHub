# Daily ops (or per-shift if 24/7)

**Purpose.** The box stays usable without the founder camping.

**Steps.**
1. Photo: lid, price card, floor, error lights.
2. Tally cycles from the machine counter or QR dashboard. Write the number in `lean/learning-log.md` weekly; daily on paper/phone is fine.
3. Empty coin if used; do not pocket into household cash (Profit First INCOME only).
4. Wipe chamber. If it looks like a wet market stall, Rule 3 has failed.

**Standard.** One visit or remote check per day in week 1; then the lightest cadence that keeps downtime < 10% of hours.
